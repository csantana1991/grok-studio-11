NucMed Board Studio — open on your computer or your own site
============================================================

This preview window cannot jump to Wikipedia, PubMed, or a new tab.
That is why Open / Google Images / “Open full page” look dead here.

To run Board Studio somewhere else:

1. Download NucMed-Board-Studio.zip
2. Unzip it. Keep this folder together:
     NucMed-Board-Studio.html
     assets/dr/
     assets/thumbs/
3. Open NucMed-Board-Studio.html in Chrome or Safari
   (double-click, or drop the folder onto any static host:
   GitHub Pages, Netlify, your clinic server).

Do not upload the HTML file alone — plates live in assets/dr.
Live Wiki/PubMed stills need internet. Teaching plates work offline.

RAD REVIEW Ultimate is a widget inside Board Studio. Use
“Open full page” to expand it in this same window (iPad blocks nested frames).
