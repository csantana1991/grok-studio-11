# Teaching Studios

Two self-contained study studios in one app.

- **CSCE Master's Studio** is a spoken walk through the Texas A&M CSCE graduate catalog, public lecture links, and a 36-credit study log. It is not a diploma, not advising, and not affiliated with Texas A&M.
- **NucMed Board Studio** is an image-and-audio board-review course. Educational use only. Not for patient care, and not affiliated with ABNM, ABR, or any residency.

## Run

```bash
npm install
npm run dev
```

Open the home page, then either studio. Course progress stays in the browser.
